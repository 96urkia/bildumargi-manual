# Manual de Bildumargi

Manual de instalación y uso de [Bildumargi](https://github.com/96urkia/bildumargi).

Se lee en <https://96urkia.github.io/bildumargi-manual/>. Se publica solo, con
GitHub Actions, cada vez que cambia algo en `docs/` o en `mkdocs.yml`.

Para verlo en local: `pip install -r requirements-docs.txt` y
`mkdocs serve -a 127.0.0.1:8001`.
